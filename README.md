# Design and Analysis of a Strain-Wave Helical Gear

Academic project completed as part of my B.Tech. in Mechanical Engineering with Specialization in Automotive Engineering at VIT Vellore.

## Overview

This project focused on the conceptual design and analysis of a strain-wave helical gear system and its associated High-Pressure Die Casting (HPDC) mould.

The gear and mould were designed using SOLIDWORKS, followed by casting simulations and structural analysis to evaluate the performance of the mould design.

## Work Performed

- Designed a strain-wave helical gear system using SOLIDWORKS.
- Developed an HPDC mould for the gear component.
- Evaluated front-stroke and back-stroke die configurations.
- Performed casting simulations using Altair Inspire Cast.
- Analysed filling behaviour, temperature distribution, erosion and solidification.
- Performed Fluent–Static Structural FSI analysis to evaluate die stress, strain and deformation.
